# 종목 화면

S&P 500 목록에서 종목을 찾는 화면입니다. 찾은 종목은 행을 눌러 종목 브리핑(오른쪽 패널)으로 열고, 콜 화면은
브리핑의 `콜 화면 열기` 로 들어갑니다. 흐름과 이유는 [UX 문서](../ux.md)에, 재질과 색은
[디자인 시스템](../design-system.md)에 있습니다.

코드는 `trading-terminal/src/renderer/pages/MarketPage.tsx`(경로 `/stocks`)와
`components/market/StockMarketTable.tsx` · `components/market/MarketMap.tsx` 에 있고, 필터 · 표시 계산은
`lib/stocksScreen.ts` 에, 지도 배치 계산은 `lib/marketMap.ts` 에 단위 테스트와 함께 있습니다.

## 들어오는 길

- 왼쪽 메뉴의 `종목`
- 홈의 "내 종목의 다가오는 콜" 이 비어 있을 때의 `종목 찾기`

## 영역

위에서부터 머리줄, 도구줄, 종목 표(또는 시장 지도) 순서입니다.

### 머리줄

| 위치 | 내용 |
|---|---|
| 왼쪽 | 화면 제목 `종목`, 그 아래 `S&P 500 · 시가총액 순`. 그 옆에 보기 전환 `표` · `지도` |
| 오른쪽 | 지금 필터 · 검색에 맞는 종목 수. 표 보기에서만, 목록을 받은 뒤에 보입니다 |

- 처음에는 `표` 로 엽니다. 숫자 표는 지도와 별개로 그대로 둡니다.
- `지도` 에서는 도구줄(필터 · 검색)과 페이지 넘김을 감춥니다. 지도는 늘 시가총액 상위 100종목 전체를 그립니다.

### 도구줄

표 보기에서만 보입니다.

| 위치 | 내용 |
|---|---|
| 왼쪽 | 필터 세그먼트 `전체` · `관심` · `보유` · `이번 주 콜`. 칸마다 해당 종목 수를 답니다 |
| 오른쪽 | 검색칸. 티커와 회사명을 대소문자 구분 없이 찾습니다 |

- 필터는 S&P 500 목록 안에서 거릅니다. 관심 종목이라도 S&P 500 밖의 종목은 이 화면에 나오지 않습니다.
- 검색은 고른 필터 안에서 찾습니다. 필터나 검색어를 바꾸면 첫 페이지로 돌아갑니다.
- 검색칸에서 Esc 를 누르면 검색어를 지웁니다.
- `이번 주 콜` 칸의 수는 실적 콜 일정을 받은 뒤에 답니다.

| 필터 | 기준 |
|---|---|
| 관심 | 관심 종목 목록(`useWatchlist`)에 있는 종목 |
| 보유 | 잔고(`usePortfolioStore` 의 보유 종목) 중 수량이 0보다 큰 종목 |
| 이번 주 콜 | 실적 콜 일정(`useEarningsTimeline`)의 진행 중 · 오늘 · 내일 · 이번 주 묶음에 있는 종목 |

### 종목 표

구름 판 하나에 표를 두고, 아래쪽에서 50개씩 페이지를 넘깁니다. 정렬은 시가총액 순으로 고정입니다.

| 열 | 내용 |
|---|---|
| `#` | 필터 결과 안의 순번. 번호라 Mono 글꼴 |
| `티커` | Mono 글꼴 |
| `회사명` | 회사명과 표시(아래) |
| `섹터` | 창이 넓을 때만 보입니다 |
| `시가총액` · `현재가` | 자릿수를 맞춘 숫자 |
| `일일` | 하루 등락률. `▲ +1.23%` · `▼ −0.50%` 처럼 기호를 함께 씁니다 |

- 현재가와 등락률은 실시간 시세가 있으면 그 값을, 없으면 목록에 실려 온 값을 씁니다. 실시간 시세가 전일 종가를
  모르면(0) 목록의 전일 종가로 등락률을 계산하고, 그것도 없으면 `—` 로 둡니다.
- 회사명 옆 표시는 모두 무채색입니다. 관심 종목은 별, 보유 종목은 `보유`, 이번 주 콜이 있으면 `콜 10/8 (목)` 처럼
  한국 시간 날짜를 붙입니다. 날짜에 한글 요일이 섞여 Mono 대신 자릿수만 맞춥니다. 색은 가격 등락에만 쓰기 때문에 표시에는 빨강 · 파랑 · 금을 쓰지 않습니다.
- 행 어디를 눌러도 종목 브리핑이 열립니다. 키보드와 스크린리더에서는 티커 칸의 버튼("WMT 종목 브리핑 열기")으로
  엽니다. 행 자체를 포커스 자리로 두지 않는 것은 표의 행 의미를 지키고, 현재가 · 등락률이 행 이름에 가려지지 않게
  하기 위해서입니다. 포커스는 금색 바깥선으로 보입니다.
- 행에서 콜 화면으로 바로 가는 버튼은 두지 않습니다. 콜 화면은 브리핑에서 일정과 지난 반응을 본 뒤 들어가는
  흐름(콜 준비)을 따릅니다.

### 시장 지도

구름 판 안에 면적 지도 하나를 둡니다. 시가총액 상위 100종목을 섹터별로 묶고, 면적은 시가총액, 칸 색은 일일
등락률입니다.

| 요소 | 내용 |
|---|---|
| 안내 줄 | "시가총액 상위 100종목 · 면적은 시가총액, 색은 일일 등락률 · 섹터 이름을 누르면 그 섹터만 봅니다". 확대 중이면 `전체` 버튼과 `/ 섹터 이름` |
| 섹터 머리 | 섹터 칸 위쪽의 섹터 이름(한국어, 예: 정보기술 · 금융). 누르면 그 섹터가 판을 채웁니다 |
| 종목 칸 | 티커와 등락률(`▲ +1.23%`). 칸이 작으면 등락률, 더 작으면 글자를 생략합니다. 누르면 종목 브리핑이 열립니다 |
| 정보 줄 | 칸에 올리거나 포커스를 두면 "티커 회사명 · 섹터 · 시가총액 · 일일" 을 씁니다 |

- 상위 100종목은 서버가 매긴 시가총액 순위(`marketCapRank`)로 고릅니다. 순위가 없는 이전 서버 응답이면
  시가총액 순으로 100개를 고릅니다. 시가총액을 모르는 종목은 면적을 줄 수 없어 빠집니다.
- 색은 앱의 가격 규칙 그대로 상승 빨강 · 하락 파랑이고, ±3% 에서 가장 진합니다. 등락률을 모르면 회색, 0% 는
  옅은 무채색입니다. 등락률은 표와 같은 규칙(실시간 시세 우선)으로 정합니다.
- 섹터와 종목 칸은 정사각형에 가깝게 나눕니다(squarified treemap). 칸은 종목별 자리를 기억해, 섹터를 확대 ·
  복귀할 때 제자리에서 커지고 줄어듭니다. 창 크기를 바꾸는 동안에는 칸이 늦게 따라오지 않도록 이 움직임을 끕니다.
- 섹터 머리를 둘 수 없을 만큼 작은 섹터는 머리 없이 칸만 둡니다. 이런 섹터는 확대하지 않고 칸을 눌러 브리핑을
  엽니다.
- 키보드: 섹터마다 머리 다음에 그 섹터의 칸이 오도록 Tab 순서를 둡니다. 확대하면 포커스가 `전체` 로, 돌아오면
  방금 연 섹터 머리로 옮겨 갑니다.
- 장 마감 뒤에도 당일 등락률이 남습니다(서버가 마감 뒤 시세로 확정합니다). 1~50위는 장중 실시간, 51~100위는 5분마다
  갱신되므로 칸 색이 바뀌는 간격이 다릅니다.

## 상태

| 상태 | 표시 |
|---|---|
| 불러오는 중 | 표 · 지도 자리에 흐린 막대 10줄 |
| 지도에 그릴 종목 없음 | "시가총액 정보가 있는 종목이 없어 지도를 그릴 수 없습니다." |
| 목록 실패 | "종목 목록을 불러오지 못했습니다." 와 실패 사유, `다시 시도` |
| 일정 실패 | `이번 주 콜` 필터에서만 "실적 콜 일정을 불러오지 못했습니다." 와 `다시 시도`. 다른 필터는 그대로 씁니다 |
| 검색 결과 없음 | "\"검색어\" 검색 결과가 없습니다." (필터가 있으면 "관심 종목 중 …") 와 `검색어 지우기` |
| 필터 결과 없음 | 필터마다 무엇이 없는지와 언제 생기는지를 씁니다. 예: "관심 종목이 없습니다. 종목 브리핑에서 관심 종목을 더하면 여기에 모입니다." |

실패 사유는 오류 종류에 따라 씁니다.

| 오류 | 사유 | `다시 시도` |
|---|---|---|
| 네트워크 | 서버에 연결하지 못했습니다. 네트워크 연결을 확인해 주세요. | 있음 |
| 서버 오류 | 서버가 응답하지 않습니다. | 있음 |
| 로그인 필요 · 만료 | 로그인이 만료되었습니다. 다시 로그인해 주세요. | 없음. 다시 시도해도 같은 실패입니다 |
| 그 밖 | 잠시 뒤 다시 시도해 주세요. | 있음 |

목록은 앱이 받은 적이 있으면 main 프로세스가 캐시를 돌려주므로, 실패 표시는 처음 받을 때만 나옵니다. 캐시가 있는데
새로 받지 못한 경우는 마지막 목록을 그대로 보여 줍니다.

## 정하지 않은 것

| 항목 | 상태 |
|---|---|
| 정렬 바꾸기 | 시가총액 순 고정입니다. 등락률 · 다음 콜 순 정렬은 필요가 확인되면 더합니다 |
| 목록 범위 | S&P 500 만 다룹니다. 범위를 넓히는 것은 이번 개편 범위가 아닙니다 |
