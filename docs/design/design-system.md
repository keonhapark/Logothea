# 디자인 시스템

Logothea 앱 화면의 시각 기준을 정리한 문서입니다. 재질, 색, 글자, 형태, 움직임, 컴포넌트 사용 규칙, 상태 패턴,
문구 규칙을 다루며 화면을 만들거나 고치는 기여자를 위한 문서입니다. 화면 구조와 흐름은 [UX 문서](ux.md)에서,
이름 · 말투 · 로고는 [브랜드 문서](brand.md)에서 다룹니다.

토큰 값의 기준은 코드의 토큰 파일(`trading-terminal/src/renderer/styles/tokens.css`)입니다. 이 문서는 쓰는 규칙과
이유를 남깁니다. 재질은 같은 폴더의 `global.css` 에 `cloud` · `cloud-s` · `dent` · `glass` · `read` · `rim` · `gbtn`
클래스로 있습니다.

## 컨셉

읽는 면은 부푼 구름이고, 그 위에 떠서 조작하는 것은 투명 유리입니다. 구름은 클레이처럼 불투명하고 두께가 있어 긴
글을 차분하게 받쳐 주고, 유리는 채움이 거의 없이 반사광 · 굴절 · 떨어지는 그림자로 내용 위에 떠 있음을 보여 줍니다.
작은 항목에는 얇은 금테를 두릅니다. 금테는 비잔틴 유리 모자이크의 금박에서 가져왔고, 버튼에 쓰는 라피스 · 올리브 ·
포르피라는 그리스 · 비잔틴을 떠올리게 하는 색입니다.

| 원칙 | 내용 | 이유 |
|---|---|---|
| 읽는 면은 구름 | 자막, 종합 판단, 홈 카드, 목록처럼 넓게 읽는 판은 구름입니다 | 불투명이라 뒤가 비치지 않아 긴 글이 흔들리지 않고, 흐림을 쓰지 않아 가볍습니다 |
| 조작층은 투명 유리 | 메뉴, 콜 바, 버튼이 투명 유리입니다. 글 위에 뜨는 팝오버 · 시트 · 모달은 흐림과 채움을 더한 읽는 유리입니다 | Apple 규칙과 같습니다. 조작 요소가 내용 위에 떠 있음을 보여 줍니다 |
| 금테는 작은 항목에만 | 칩, 배지, 세그먼트 썸, 열린 콜 자리, 고른 메뉴 · 탭에만 두릅니다. 판 · 콜 바 · 버튼에는 두르지 않습니다 | 넓은 면에 두르면 금이 화면을 덮어 장식이 내용보다 앞섭니다 |
| 색상 유리는 버튼에만 | 라피스 · 올리브 · 포르피라 유리는 버튼에만 씁니다 | 색이 있는 면은 누를 수 있는 것이라는 뜻을 지킵니다 |
| 색상 유리 주 버튼은 화면에 하나 | 한 화면에서 가장 중요한 행동 하나만 색상 유리로 둡니다. 주문 시트처럼 화면 위에 따로 열리는 판은 그 안에서 따로 셉니다 | 다음에 할 일을 하나로 좁힙니다 |
| 바탕은 옅은 빛 | 단색 바탕에 브랜드 세 색과 금을 아주 옅은 빛으로 네 귀퉁이에 깝니다 | 투명 유리는 뒤에 비칠 것이 있어야 유리로 보입니다. 내용을 가리지 않을 만큼만 둡니다 |
| 두 테마, 같은 재질 | 다크와 라이트를 둡니다. 재질과 규칙은 같고 값만 다릅니다. 기본은 운영체제 설정을 따르고, 설정 화면에서 고정할 수 있습니다 | 콜은 밤에도 낮에도 열립니다. 테마마다 재질이 다르면 규칙이 두 벌이 됩니다 |

## 재질

값은 테마마다 다르고 토큰 파일에 있습니다. 아래는 구조와 이유입니다. 광원은 왼쪽 위에 하나만 둡니다. 모든 반사광과
그림자는 이 광원을 따릅니다.

### 구름

라쿤봇팩토리 클레이(부풂 · 눌림 · 패임, 두 겹 색 그림자)를 판 크기로 키운 재질입니다.

| 클래스 | 쓰는 곳 | 모양 |
|---|---|---|
| `cloud` | 자막 · 판단 · 홈 카드 · 목록 · 설정 판 | 비스듬한 그라데이션 몸체에 안쪽 위 밝은 빛, 안쪽 아래 어두운 빛, 바깥 두 겹 그림자(`--puff-big`) |
| `cloud-s` | 판 안의 칩 · 대조 카드 · 배지 · 세그먼트 썸 | 같은 몸체에 작은 그림자(`--puff-small`) |
| `dent` | 세그먼트 트랙 · 검색칸 · 판 안의 입력 자리 | 눌린 자리. 안쪽 그림자만 둡니다(`--press`) |

라이트의 그림자는 검정 대신 남색이 섞인 보랏빛을 써서 구름이 뭉글뭉글하게 보이게 합니다. 구름은 불투명이라
`backdrop-filter` 를 쓰지 않습니다.

### 투명 유리 (`glass`)

메뉴, 콜 바, 버튼, 드롭다운처럼 위에 떠서 조작하는 층입니다. 채움은 거의 없고(다크 흰색 5%, 라이트 흰색 10%) 다음
층으로 유리임을 보입니다.

| 층 | 내용 |
|---|---|
| 배경 처리 | 굴절 맵 + `blur(2px) saturate(1.5)` + 밝기 |
| 가장자리 반사광 | 왼쪽 위에서 들고 맞은편 아래 가장자리에도 되비치는 1.2px 띠 |
| 안쪽 빛 | 안쪽 가장자리의 옅은 흰 빛 |
| 두께 | 안쪽 아래 어두운 띠 + 안쪽 위 밝은 띠(`--glass-thick`) |
| 떨어지는 그림자 | 두 겹(`--glass-cast`) |

라이트에서는 유리가 바탕과 비슷하게 밝아 구분이 약합니다. 윤곽선 · 배경 광원 · 마우스 반사광을 시험했지만 효과가
작아 쓰지 않고, 떨어지는 그림자와 가장자리 두께만으로 구분합니다.

**유리 안의 유리**: 브라우저는 유리 안에 든 유리에게 바깥 유리만 보여 줍니다. 그래서 유리 안의 유리 · 버튼은
흐림을 끄고 반사광 · 두께만 남깁니다.

**굴절**: 부품마다 크기와 모서리 반경에 맞춘 굴절 맵을 만들어 가장자리에서 뒤를 휘게 합니다. 단면은 렌즈
모양(`1 − √(1 − t²)`)입니다. SVG `feDisplacementMap` 을 `backdrop-filter` 에 거는 방식이며 Electron(Chromium)을
대상으로 합니다. 굴절 값과 흐림 값은 따로 넣습니다. 굴절을 모르는 엔진(Safari 등)이 값 전체를 버려 흐림까지
사라지지 않게 하기 위해서입니다.

굴절을 건 유리 뒤는 Chromium 이 부드럽게 다시 그려 글자가 흐려집니다. 그래서 굴절은 뒤를 읽을 필요가 없는 조작층에만
겁니다. #154 에서 움직이는 글 위에 판 · 캡슐 · 버튼 10개를 겹쳐 재 보았을 때 굴절을 켠 경우와 끈 경우의 프레임
시간이 같았습니다(120Hz 화면에서 평균 8.3ms, Chrome 154). 굴절 맵은 크기가 바뀔 때만 다시 만들고, 투명도 줄이기
설정이 켜져 있으면 끕니다.

### 읽는 유리 (`read`)

용어 설명, 주문 시트, 종목 브리핑, 모달처럼 글 위에 뜨는 판입니다. 투명 유리와 같은 반사광 · 두께에 `blur(30px)` 와
채움(라이트 흰색 62%, 다크 짙은 회색 66%)을 더해 아래 글자와 섞여 읽히지 않게 합니다.

### 금테 (`rim`)

금속 선입니다. 금색 다섯 단계를 원뿔 그라데이션으로 돌려 빛을 받는 금속처럼 보이게 합니다.

| 굵기 | 쓰는 곳 |
|---|---|
| 1px | 칩, 배지, 세그먼트 썸, 고른 탭 |
| 1.4px (`rim-float`) | 고른 메뉴, 열린 콜 자리 |

금테는 장식이므로 뜻을 싣지 않습니다. 상태나 결과를 금테 굵기로 구분하지 않습니다.

### 색상 유리 (버튼 전용)

색을 덮어 칠하지 않고 빛처럼 더합니다. 가운데는 맑게 두고, 색은 가장자리 테 · 바닥 투과광 · 바깥 글로우에
모읍니다. 어두운 색을 반투명하게 덮으면 바탕과 섞여 탁해지기 때문입니다.

| 층 | 값 (`c` 는 아래 색상 유리 색, `k` 는 테마별 세기: 다크 1, 라이트 0.75) |
|---|---|
| 몸체 | 위에서 아래로 `c` 14% → 6%, × `k` |
| 바닥 투과광 | 아래 가운데에서 퍼지는 `c` 42%, × `k` |
| 배경 처리 | 굴절 맵 + `blur(2px) saturate(1.9)` + 밝기 |
| 윗면 반사선 | 안쪽 위 1px, 흰색 90% |
| 가장자리 테 | 안쪽 1px `c` 60%, 안쪽 14px `c` 32% |
| 바닥 빛 | 안쪽 아래 `c` 75% |
| 바깥 글로우 | 아래 6px, 흐림 22px, `c` (다크 50%, 라이트 30%) |
| 글자 | 다크는 흰색에 글자 그림자, 라이트는 같은 색 계열의 짙은 글자(그림자 없음) |

## 색상 유리 (버튼 전용)

색을 덮어 칠하지 않고 빛처럼 더합니다. 가운데는 맑게 두고, 색은 가장자리 테 · 바닥 투과광 · 바깥 글로우에
모읍니다. 어두운 색을 반투명하게 덮으면 바탕과 섞여 탁해지기 때문입니다.

| 층 | 값 (`c` 는 아래 색상 유리 색) |
|---|---|
| 몸체 | 위에서 아래로 `c` 14% → 6% |
| 바닥 투과광 | 아래 가운데에서 퍼지는 `c` 42% |
| 배경 처리 | 굴절 맵 + `blur(1.5px) saturate(1.9) brightness(1.12)` |
| 윗면 반사선 | 안쪽 위 1px, 흰색 90% |
| 가장자리 테 | 안쪽 1px `c` 60%, 안쪽 14px `c` 32% |
| 바닥 빛 | 안쪽 아래 `c` 75% |
| 바깥 글로우 | 아래 6px, 흐림 22px, `c` 50% |
| 반사광 | 위쪽 흰색 34% → 0, 왼쪽 위 흰색 40% |
| 글자 | 흰색, 글자 그림자에 `c` 45% 번짐 |

| 투명 유리 | 색 없음 | 색 없음 | 보조 행동 | 취소, 관심종목 추가 |

### 가격

| 토큰 | 다크 | 라이트 | 뜻 |
|---|---|---|---|
| `up` | `#ff5a5f` | `#c03036` | 상승 |
| `down` | `#5b9bff` | `#2861d4` | 하락 |

한국 관례대로 상승은 빨강, 하락은 파랑입니다. 가격에만 쓰고 장식이나 다른 뜻에 쓰지 않습니다. 등락은 색과 함께
`▲` `▼` 기호를 붙입니다.

하락 파랑과 라피스는 색이 가깝습니다. 그래서 쓰는 자리를 나눕니다. 하락 파랑은 글자(가격 · 등락)에만 쓰고 면에는
쓰지 않습니다. 라피스는 버튼 면에만 쓰고 글자나 숫자에는 쓰지 않습니다. 매수 · 매도처럼 가격 방향과 이어지는
선택에는 라피스를 쓰지 않습니다. 대신 매수 · 매도 글자에는 한국 증권 관례대로 상승 빨강 · 하락 파랑을 씁니다.

### 상태

| 토큰 | 다크 | 라이트 | 뜻 |
|---|---|---|---|
| `ok` | 올리브 `#b0cc52` | `#587011` | 정상 · 연결됨 · 체결 |
| `danger` | `#ff8a5c` | `#ae4825` | 오류 · 실패 · 만료 |
| `caution` | 금 `#e2bd62` | `#8b5f0e` | 주의 · 진행 중 |

라이트의 상태 · 가격 색은 바탕과 구름 위에서 글자 대비 4.5:1 이상이 되도록 다크보다 짙게 둡니다.

오류에 빨강을 쓰지 않는 이유는 상승 빨강과 헷갈리기 때문입니다. 상태 색은 글자와 작은 점에만 쓰고 늘 문구와 함께
둡니다. LIVE 처럼 콜 진행을 알리는 표시는 무채색 점멸로 나타냅니다.

### 직전 콜 대조

대조 칩은 작은 구름에 금테 1px 이고, 결과는 글자색과 기호로 나타냅니다. 색상 유리는 버튼에만 쓰기 때문에 칩에는 쓰지 않습니다.

| 결과 | 기호 | 글자색 |
|---|---|---|
| 개선 | `+` | 올리브 |
| 후퇴 | `−` | 포르피라 |
| 혼재 | `±` | `ink-2` |
| 변화 없음 | `=` | `ink-3` |
| 새 언급 | `∗` | `ink-3` |

색만으로 구분하지 않습니다. 기호와 문구를 늘 함께 둡니다. 포르피라와 상승 빨강은 색각 이상이 있으면 비슷하게
보일 수 있어서입니다.

`후퇴` 이거나 위험 점수가 높은 항목은 칩 대신 펼친 카드로 보여 줍니다. 포르피라 글자로 `− 후퇴 ·
주제` 머리를 달고, 아래에 직전 발언과 이번 발언 원문을 나란히 둡니다. 카드는 작은 구름입니다. 흰 판 위에 맑은 유리
카드를 두면 가장자리로만 보여 유리감이 없어 구름으로 두었습니다.

### 종합 판단

| 항목 | 표시 |
|---|---|
| 실행 판단(권고 행동) | 색 없이 `ink-1` 24px 로 씁니다. 판단의 첫 줄입니다 |
| 실행 조건 | 통과는 올리브 글자, 조건부 보류는 `ink-2`, 차단은 포르피라 글자 |
| 방향(강세 · 약세 · 중립) | 색 없이 글자로만 씁니다. 상승 · 하락 색과 섞이지 않게 하기 위해서입니다 |
| 근거 확인 여부 | 확인은 올리브 글자, 확인하지 못함은 `ink-3` |

## 컴포넌트

### 버튼

| 종류 | 재질 |
|---|---|
| 주 행동 | 라피스 색상 유리 |
| 확인 | 올리브 색상 유리 |
| 위험 | 포르피라 색상 유리 |
| 보조 | 투명 유리 |

버튼에는 금테를 두르지 않습니다.

색상 유리는 색을 옅게 비치게 둡니다. 작은 버튼이라 색이 잘 보이지 않는 자리에는 색을 더 채운 변형
(`gbtn-strong`, 바닥 투과광 0.7 · 면 0.2 ~ 0.34)을 씁니다. 지금은 홈 계좌 판의 `포트폴리오에서 자세히` 하나입니다.

| 크기 | 글자 | 안쪽 여백 |
|---|---|---|
| 큰 | 15px | 16px 28px |
| 기본 | 14px | 12px 20px |
| 작은 | 12.5px | 8px 16px |
| 아이콘 | 16px 아이콘 | 44 × 44px, 작은 것은 36 × 36px |

상태는 기본 · 마우스 올림(밝게) · 누름(0.97) · 포커스(`gold-hi` 2px 바깥선, 3px 띄움) · 비활성(채도 20%, 밝기 80%,
불투명도 55%)입니다.

대화상자에서는 보조 버튼을 왼쪽, 색상 유리 버튼을 오른쪽에 둡니다.

### 칩

작은 구름 캡슐에 금테 1px 입니다. 글자는 12px · 650 이고, 직전 콜 대조 칩은 위 대조 색 규칙을 따릅니다.

### 세그먼트

눌린 자리 트랙 안에서 썸이 스프링으로 미끄러집니다. 썸은 작은 구름에 금테 1px 입니다. 색상 유리는
버튼에만 쓰므로 썸에는 쓰지 않습니다. 고른 칸의 글자는 650 굵기로 올립니다.

### 판 · 콜 바 · 시트

판은 구름, 메뉴와 콜 바는 투명 유리, 주문 시트 · 종목 브리핑 · 모달은 읽는 유리입니다. 판 · 콜 바 · 시트에는
금테를 두르지 않습니다. 주문 시트를 투명 유리로 두었더니 뒤의 글자가 비쳐 입력값과 섞여 읽혀서 읽는 유리로
두었습니다.

떠 있는 콜 바 아래로 내용이 지나가는 면은 위쪽을 판 색으로 서서히 덮습니다(스크롤 가장자리). 바의 블러가 약해
바로 아래 글자와 바의 글자가 겹쳐 읽히기 때문입니다.

| 항목 | 규칙 | 예 |

| 가운뎃점 | 앞뒤를 한 칸씩 띄웁니다 | `Walmart · Q2 FY27` |

| 시각 | 한국 시간으로 쓰고, 필요하면 미국 동부 시간을 덧붙입니다 | `오후 9:00 KST (미 동부 오전 8:00)` |
| 경과 시간 · 자막 시각 | `mm:ss`, 60분을 넘으면 `h:mm:ss` | `02:00`, `1:04:30` |
| 버튼 | 무엇이 일어나는지를 명사구나 짧은 동사구로 씁니다 | `주문 확인`, `콜 화면 열기` |

## 접근성

- 본문 · 보조 · 설명 글자(`ink-1` ~ `ink-3`)와 상태 · 가격 색은 두 테마 모두 바탕과 구름 위에서 4.5:1 이상을
  지킵니다. 다크의 유리 위 글자는 글자 그림자로 이 대비를 유지합니다. `ink-4` 는 비활성 · 자리 표시용이라 3:1 남짓입니다.
- 색만으로 뜻을 구분하지 않습니다. 가격은 `▲` `▼`, 대조는 `+` `−` 기호를 함께 둡니다.
- 키보드 포커스는 금색 바깥선으로 늘 보이게 합니다.
- 움직임 줄이기 · 투명도 줄이기 설정을 따릅니다.
